# Projet de statistiques — Des chiffres et des drogues

Projet académique réalisé à l'INSA Rouen Normandie dans le cadre d'un projet de statistiques.

## Description

Ce projet porte sur l'analyse statistique d'un jeu de données consacré aux comportements de consommation de substances psychoactives.

Le dataset contient **1 889 individus et 31 variables**, regroupant notamment :

* des caractéristiques sociodémographiques ;
* des variables psychométriques issues de tests de personnalité ;
* des données relatives à la consommation de différentes substances.

L'objectif du projet est d'étudier les relations entre ces différentes variables à l'aide de méthodes statistiques et de modèles de régression.

## Méthodes utilisées

L'analyse réalisée dans le rapport comprend notamment :

* description et préparation des données ;
* analyse des corrélations ;
* régressions linéaires multiples ;
* régressions linéaires simples ;
* tests statistiques, notamment le test t de Student ;
* interprétation des résultats et discussion des limites des modèles.

Les analyses portent notamment sur les relations entre certains traits psychologiques, comme l'impulsivité et la recherche de sensations fortes, et différentes variables de consommation.

## Rapport

Le rapport présente l'ensemble de la démarche, depuis la description et la préparation du dataset jusqu'à l'analyse statistique et l'interprétation des résultats.
